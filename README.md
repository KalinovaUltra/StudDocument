# Система автоматизации документооборота для студентов

**Кратко:** Веб-приложение для студентов, деканата и профкома.  
Подача заявлений, отслеживание статуса, генерация Word-документов и вложений.

<br>

## Технологии
- **Backend:** Django, Python, SQLite  
- **Frontend:** HTML, CSS, JavaScript 
- **Генерация документов:** docxtpl, python-docx 
- **Дизайн прототипов:** Figma

<br>

## Основные возможности
- Роли: студент, деканат, профком, администратор  
- Динамические формы под тип документа  
- Предварительный просмотр документа  
- Скачивание сгенерированного Word‑файла  
- Прикрепление файлов (zip‑архив)  
- Изменение статусов заявок  
- Редактирование профиля
